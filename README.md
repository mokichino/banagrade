# BanaGrade 🍌

**BanaGrade** is a web-based AI-assisted banana grading system designed to assess the **disease condition and quality of Philippine Cardava bananas (Musa balbisiana)** using RGB image analysis and machine learning.

The system is designed to support packing-house operations by providing an automated and consistent approach to banana assessment. It uses computer vision and an AI classification model to identify healthy and unhealthy bananas and assist in determining their quality acceptance.

### Key Features

* 📷 RGB image-based banana assessment
* 🤖 AI-assisted disease classification
* 🍌 Cardava banana quality grading
* 🔍 Detection of visible disease conditions
* 📊 Web-based monitoring and assessment dashboard
* ✅ Healthy/acceptable and unhealthy/rejected classification
* 💡 Designed for low-cost implementation in Philippine packing-house environments

BanaGrade is developed as part of a **Bachelor of Science in Computer Science thesis** focused on applying artificial intelligence and computer vision to improve banana quality assessment and post-harvest handling.
